# ACXC16-VPS新机一键脚本

Ubuntu / Debian VPS 初始化：状态表 + 编号菜单，选一项做一项，做完自动回到菜单。

```bash
curl -fsSL https://github.com/ACXC-16/ACXC-VPS-ONECLICK/releases/latest/download/init.sh | bash
```

首次运行会**自动装好快捷命令**，以后在 VPS 上直接输入 **`acxc`** 就能打开。

## 各选项

| 选项 | 做什么 |
| --- | --- |
| 1 | `apt update` 后**只升级内核 / 驱动 / 固件**，其它软件一个都不动；需要重启会提示 |
| 2 | 选完再问一次：**① 使用默认设置**（SSH 端口 `52052`、root 密码 `acxc1616`）**② 自定义** **③ 不修改**。改端口带备份 → `sshd -t/-T` 校验 → 失败自动回滚；默认保留旧端口过渡 |
| 3 | 逐项勾选：常用工具（标了 `[推荐]` / `[按需]`）、fail2ban、时区、Swap、BBR |
| 4 / 5 | 查看系统信息 / 最近 40 行日志 |
| 6 | 更新脚本：拉取最新发布版并刷新本地缓存，会报出版本变化 |

跑完（或选 0 退出）时，结束界面会**再列出本次设置的 SSH 端口和 root 密码**，方便你保存。明文密码只显示在屏幕上，**不会写进日志**。

## 几个说明

- **改 SSH 端口前**先在云服务商安全组放行新端口；改完别关当前窗口，另开终端 `ssh -p 新端口 root@IP` 验证成功再关旧连接。
- `acxc1616` 是脚本内置的默认密码，**容易被猜到**：登录后建议尽快走「2) 修改 SSH 端口 / root 密码 → 自定义」改成自己的强密码。
- 回滚：`cp -a /root/vps-init-backup/<时间戳>-ssh/. /etc/ssh/ && systemctl restart ssh`
- 日志：`/var/log/vps-init.log`；卸载快捷命令：`rm /usr/local/bin/acxc`
- 无人值守：`| bash -s -- --yes`（**不会**自动改 root 密码）；只跑某项：`--only sysupdate`；演练：`--dry-run`；全部参数：`--help`
- 只在 Ubuntu / Debian（含衍生版）上测试过；其它发行版需要 `--force`，风险自负。
