# ACXC16-VPS新机一键脚本

Ubuntu / Debian VPS 初始化：状态表 + 编号菜单，选一项做一项，做完自动回到菜单。

```bash
curl -fsSL https://github.com/ACXC-16/ACXC-VPS-ONECLICK/releases/latest/download/init.sh | bash
```

首次运行会**自动装好快捷命令**，以后在 VPS 上直接输入 **`acxc`** 就能打开（秒开，不会每次去联网）。

每次执行完会清屏回到这个界面；进二级菜单前也清屏，屏幕上只留当前这一步。输入不合法的编号或字母时会**就地提示并重新询问**（例如提示"无效的选择：acxc（请输入 0-8；退出请输入 0）"），菜单和列表不会重复出现。所有画面（主菜单、每个步骤、二级菜单）顶部都会先显示这个 `ACXC` 大字图标，再加一行当前所在位置的副标题。二级菜单里**什么都没做就选 0** 会直接回主菜单，不用再按一次回车；做完动作也会直接回主菜单，不重复显示列表。

选 `0` 退出时**直接安静退出**：不打印任何多余文字（没有告别语、没有汇总、没有提示）；退出后菜单留在屏幕上、提示符紧随其后，不做任何光标跳转或屏幕切换（避免不同终端上出现乱码）。端口、密码这些细节在执行的那一刻就已经显示过了，事后也可以回头看 `5) 查看运行日志`（日志文件 `/var/log/acxc-vps.log`）。

> 无人值守运行（`--yes` / `--only`）不会切备用屏幕，输出直接留在当前屏幕上，方便重定向和查看。

> 想让**全程都不清屏**（每一步的输出都连着往下排，方便滚动查看）：用 `ACXC_VPS_CLEAR_SCREEN=0 acxc` 启动即可（默认是进菜单/进二级菜单时清屏重画）。

## 各选项

**1) 更新内核 / 驱动 / 固件** —— 三组可多选（编号之间用空格隔开）：

```
  1) 驱动（CPU 微码 / 驱动模块）        2) 固件（firmware）
  3) 内核（image / modules / headers）  0) 返回

  多个编号之间要用空格隔开（例如：1 3）；直接回车＝全升级
```

**2) 修改 root 密码 / SSH 端口** —— 两步问答，先密码后端口：

```
  第一步：修改 root 密码
  直接回车＝不修改；想用脚本默认密码就输入：acxc1616
  请输入新的 root 密码（回车＝不修改）:

  第二步：修改 SSH 端口
  请输入新的 SSH 端口 [52052]:          ← 直接回车＝52052
```

输入端口后会先打印 4 条安全提醒，再让你确认一次才会真正动手：

```
  ① 云服务商控制台的「安全组 / 防火墙」先放行 52052/TCP
  ...
  即将修改：SSH 端口 22 → 52052（过渡期保留 22）
  确认现在执行？ [Y/n]                  ← 回答 n 则一个字节都不改
```

**3) 安装常用工具 / BBR网络加速 / Swap** —— 按使用人数与重要性排序，可多选；装完就回主菜单：

```
  可安装 / 可设置的项目：
   1) 下载与证书             推荐
   2) 防 SSH 爆破            推荐
   3) 加虚拟内存             推荐
   4) 防火墙
   5) 进程 / 端口
   6) 文本编辑
   7) 传文件 / 解压
   8) Tab 补全
   9) 磁盘占用
  10) 网络排障
  11) 设置时区
  12) BBR 加速
   0) 返回主菜单

  多个编号之间要用空格隔开（例如：1 3 5）；直接回车＝只装标了「推荐」的项目；a＝全部
```

各项目具体装什么（列表只显示短名字，这里是明细）：

| 编号 | 名字 | 实际安装 / 做的事情 |
| --- | --- | --- |
| 1 | 下载与证书 | `curl` `wget` `ca-certificates` `gnupg` |
| 2 | 防 SSH 爆破 | `fail2ban`（含 SSH jail 配置） |
| 3 | 加虚拟内存 | 创建 `/swapfile` 并写入 fstab |
| 4 | 防火墙 | `ufw`（先放行 SSH 端口再启用） |
| 5 | 进程 / 端口 | `htop` `tmux` `lsof` |
| 6 | 文本编辑 | `vim` `nano` |
| 7 | 传文件 / 解压 | `git` `rsync` `unzip` `zip` |
| 8 | Tab 补全 | `bash-completion` |
| 9 | 磁盘占用 | `jq` `tree` `ncdu` |
| 10 | 网络排障 | `net-tools` `dnsutils` `mtr-tiny` `traceroute` |
| 11 | 设置时区 | 列出 19 个常用时区供选择 |
| 12 | BBR 加速 | 开启 BBR 拥塞控制 |

每一项选中后都会再给一个**小菜单**，可以正向或反向操作：

- 列表每行右侧会显示**当前状态**（已装 / 未装 / 运行中 / 已启用 / 已开 …），一眼看出装没装
- 软件包类（1、5、6、7、8、9、10）：`1) 安装` / `2) 卸载` / `0) 跳过`
- `2) 防 SSH 爆破`：`1) 安装（装完自动启用）` / `2) 启用` / `3) 暂停` / `4) 卸载` / `0) 跳过`
- `3) 加虚拟内存`、`12) BBR 加速`：`1) 开启` / `2) 关闭` / `0) 跳过`
- `4) 防火墙`：`1) 安装并启用` / `2) 放行端口` / `3) 关闭端口` / `0) 跳过`（关 SSH 端口会二次确认）
- `11) 设置时区`：直接进时区列表

**选时区**（在第 3 项菜单里）—— 会先把全球主要时区列成编号给你挑，也能直接输时区名：

```
  常用时区（输入编号即可，也可以直接输入时区名，例如 Asia/Tokyo）：
   1) Asia/Shanghai        中国（北京 / 上海） （默认）
   2) Asia/Hong_Kong       中国香港
   ...
  19) UTC                  协调世界时
   0) 保持当前时区（不改）

  直接回车 = 1) Asia/Shanghai；也可以输入上面没有的时区，例如 Europe/Berlin
```

**UFW 防火墙**（在第 3 项菜单里）—— 顺序是**先放行 SSH 端口、再启用**，避免把自己关在门外：
自动识别当前 SSH 端口（含过渡期保留的旧端口）→ `ufw allow <端口>/tcp` → 才 `ufw enable`；可选放行 80/443。万一失联：云控制台登录后 `ufw disable`。

**7) 重启服务** —— `1) SSH`、`2) fail2ban`、`3) 重启脚本`（只把脚本重新载入，刚更新过脚本就用它）、`4) 全部重启`（= SSH + fail2ban + 脚本，最后会把脚本重新载入）；重启 SSH 不会断开你已登录的连接。

**8) 卸载 / 清理** —— 可以只做其中几项，也可以一键全清：

```
  1) 删除快捷命令与脚本缓存（acxc）
  2) 卸载脚本装过的常用工具（含 CPU 微码）
  3) 删除运行日志
  4) 还原 SSH / 删除 fail2ban、ufw、BBR、Swap 配置
  5) 完全卸载（1-4 全做，并可选删除备份）
```

每一项都会先问一次确认，**这里的确认默认都是 `Y`**（一路回车就是全清），提示长这样：`是否顺便卸载 fail2ban 软件包？ [Y/n]`。`ca-certificates`、`gnupg` 会保留（卸了会影响下载/证书），**内核不会被删**（误删可能导致无法开机）。

## 说明

- **改 SSH 端口前**先在云服务商安全组放行新端口；改完别关当前窗口，另开终端 `ssh -p 新端口 root@IP` 验证成功再关旧连接。
- `acxc1616` 是脚本内置默认密码，**容易被猜到**，登录后建议尽快改成自己的强密码。
- 回滚：`cp -a /root/acxc-vps-backup/<时间戳>-ssh/. /etc/ssh/ && systemctl restart ssh`
- 无人值守：`| bash -s -- --yes`（不会自动改 root 密码）；只跑某项：`--only sysupdate`（可用 `sysupdate` / `access` / `extras`，大小写都行，拼错会直接报错而不是静默跳过）；演练：`--dry-run`；全部参数：`--help`
- 只在 Ubuntu / Debian（含衍生版）上测试过；其它发行版需要 `--force`，风险自负。
