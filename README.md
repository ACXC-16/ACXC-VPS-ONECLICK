# ACXC16-VPS新机一键脚本

Ubuntu / Debian VPS 初始化：状态表 + 编号菜单，选一项做一项，做完自动回到菜单。

```bash
curl -fsSL https://github.com/ACXC-16/ACXC-VPS-ONECLICK/releases/latest/download/init.sh | bash
```

首次运行会**自动装好快捷命令**，以后在 VPS 上直接输入 **`acxc`** 就能打开。

## 各选项

**1) 更新内核 / 驱动 / 固件** —— 列成三组让你挑，可多选：

```
  可升级的项目：
  1) 驱动（CPU 微码 / 驱动模块）        intel-microcode ...
  2) 固件（firmware）                   linux-firmware ...
  3) 内核（image / modules / headers）  linux-image-6.8.0-147-generic
  0) 返回（什么都不做）

  多个编号之间要用空格隔开（例如：1 3）；直接回车＝全升级
```

**2) 修改 SSH 端口 / root 密码** —— 两步走，不需要选来选去：

```
  第一步：修改 SSH 端口
  请输入新的 SSH 端口 [52052]:          ← 直接回车＝用 52052

  第二步：修改 root 密码
  直接回车＝不修改 root 密码；如果想用脚本默认密码，就输入：acxc1616
  请输入新的 root 密码（回车＝不修改）:
```

结束后会显示本次改动；退出脚本时还会再汇总一次「★ 本次设置」的端口和密码。明文密码只显示在屏幕上，不会写进日志。

## 几个说明

- **改 SSH 端口前**先在云服务商安全组放行新端口；改完别关当前窗口，另开终端 `ssh -p 新端口 root@IP` 验证成功再关旧连接。
- `acxc1616` 是脚本内置的默认密码，**容易被猜到**：登录后建议尽快改成自己的强密码。
- 回滚：`cp -a /root/acxc-vps-backup/<时间戳>-ssh/. /etc/ssh/ && systemctl restart ssh`
- 卸载快捷命令：`rm /usr/local/bin/acxc`
- 无人值守：`| bash -s -- --yes`（**不会**自动改 root 密码）；只跑某项：`--only sysupdate`；演练：`--dry-run`；全部参数：`--help`
- 只在 Ubuntu / Debian（含衍生版）上测试过；其它发行版需要 `--force`，风险自负。
